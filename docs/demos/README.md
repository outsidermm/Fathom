# Cloud integration recordings

These clips were recorded on 2026-09-26 from the Vercel Preview of commit
`7054b35`, with the Vercel-hosted FastAPI WebSocket connected to live Runpod
Qwen and AV services. Preview protection required a temporary local proxy to
forward a short-lived Vercel identity header for page and WebSocket requests.
The proxy and credentials are not in this repository. No stream events were mocked.

1. [Live answer and interpretation bubbles](01-live-readings.webm): a used-car
   question streams text while checkpoint readings populate the ocean.
2. [Suggested direction](02-suggested-direction.webm): choosing the professional
   inspection bubble starts a new answer and new readings.
3. [Custom direction](03-custom-direction.webm): typing a direction about hidden
   ownership costs starts a new answer whose opening covers insurance and repairs.

AV readings are approximate interpretations of model-state snapshots. Suggested
directions are generated by Qwen. Both steering actions start a new answer using
prompt guidance; neither applies an activation edit to the existing answer.
